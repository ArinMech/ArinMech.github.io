# Arin Chaudhary — Portfolio

Personal portfolio site built with plain HTML, CSS, and JS. No framework, no build step.

## Structure

- `index.html` — page content
- `styles.css` — styling (dark/light theme aware via `prefers-color-scheme`)
- `script.js` — mobile nav toggle
- `assets/` — static assets (resume PDF)

## Local preview

Just open `index.html` in a browser, or serve it:

```
python -m http.server 8000
```

## Hosting

Deployed via GitHub Pages from the `main` branch.
